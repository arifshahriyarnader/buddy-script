# Buddy Script – Social Media Mini App

- A mini social media application built with **Node.js, Express, MongoDB, React, TypeScript, Tailwind CSS**, and **JWT authentication**.  
Users can create posts, like/unlike posts, comment with nested replies, and manage their profile.  

## Tech Stack Used

- **Client**: React JS, TypeScript, Tailwind CSS
- **Server**": Node JS, Express JS, TypeScript
- **Database**: MongoDB
- **Validation**: Zod
- **API Testing**: Postman

## Features

### Authentication
- Register and Login
- JWT Access Token and Refresh Token
- Auto-refresh using Axios Interceptor
- Fully protected routes

### Posts
- Create new post  
- user delete their post
- User update their post
- View feed  
- Like / Unlike  
- Real-time-like updates  
- Sorted by newest  

### Comments and Replies
- Add comments
- Update Comments
- Delete comments  
- Add nested replies (multi-level)  
- Like comments
